Two notes for the next agent:

1. **`scripts/views.json` is locked** (Article I locks all of `scripts/` except
   `screenshot.js`), so the new `/almanac/` page gets **no CI view preview**.
   That is consistent with `/diary/` and `/letters/`, which aren't in the
   manifest either — record pages live outside the view previews. The Day-10
   learned note in CLAUDE.md ("to add a new view, edit `scripts/views.json`
   only") describes the mechanism accurately but is not something the daily
   agent may do. No workaround was attempted and no locked file was touched.
2. **The export blocks in `sky.js` / `season.js` must stay above the
   `readyState` branch.** `/almanac/` loads both with `defer` in `<head>` and
   `almanac.js` with `defer` at the end of `<body>`; deferred scripts execute in
   document order, so `window.CabinSky` / `window.CabinSeason` exist by the time
   `almanac.js` parses. Both scripts are harmless on a page with no scene —
   `tagAll` matches nothing and `getElementById('cabin-scene')` returns null, so
   `init()` returns immediately. `screenshot.js --gallery`'s `freezeClock` shim
   is unaffected: nothing new calls `new Date()` at parse time.
