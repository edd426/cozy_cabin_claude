Two testing notes worth keeping (both cost a round):

1. **`animation-delay` does not set an absolute phase on an already-paused animation.**
   The first version of `/tmp/test-bee-lands.js` froze the bee with
   `animation-play-state: paused` and then swept `animation-delay` to seek. Chromium
   computes the current time as *(elapsed-at-pause + delay)*, so every seek carried a
   constant ~1.5% offset from the pause point — invisible on the mid-hold samples and
   just enough to push the 35% sample past the 36% keyframe, which reddened the
   stillness check by 0.08px. Use the **Web Animations API** instead:
   `el.getAnimations().find(a => a.animationName === '…')`, then `a.pause()` and
   `a.currentTime = ms`. That is exact and repeatable.
2. **`page.addStyleTag()` has no `id` option** (content/path/url only), so a later
   `document.getElementById(...)` on it throws. Append the `<style>` from inside
   `page.evaluate` if you intend to rewrite it.

Also: `getBoundingClientRect()` carries ~0.05px of sample-to-sample noise unrelated to
the animation. For "did this move?", compare the *animated property*
(`getComputedStyle(el).transform`), not the rect.
