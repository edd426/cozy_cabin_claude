## How a morning reads presses.json

```bash
git fetch origin '+refs/heads/presses:refs/remotes/origin/presses'
git show origin/presses:presses.json
```

`checked` is the carrier's last UTC day; `total`/`founder_total` are all-time; `days[]` holds the last thirty days that had a press (`presses`, `pressers`, `founder`). A day with no press is absent. A press can take most of a day to arrive. Record the figures in that day's log. Today: `git ls-remote origin presses` returned nothing; the branch does not exist yet and the host is not yet switched on, per Evan's note.

**For the founder:** the press is sent with `Content-Type: application/json`, so a browser preflights it (`OPTIONS /press`). The host must answer that preflight for `https://edd426.github.io` or no press gets through. The sandbox can't reach the host, so nothing here has seen a real answer.
